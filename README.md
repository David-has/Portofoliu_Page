## Tehnologii

HTML5, CSS3, JavaScript (fără framework-uri sau biblioteci). Design responsive, mobile first, cu mod luminos și întunecat. Fonturi: Bricolage Grotesque și Instrument Sans (Google Fonts).

## Structura proiectului

```
index.html   structura și textele paginii
style.css    stilurile, inclusiv modul întunecat
script.js    selectorul de proiecte și previzualizarea live
```

## Rulare locală

Deschide `index.html` în browser sau pornește-l cu extensia Live Server din VS Code.

Lista proiectelor din previzualizare se editează la începutul fișierului `script.js`.
